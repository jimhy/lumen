## 1. 背景

Lumen 当前有两种工作模式：

- **本地模式**：在当前电脑上创建和使用终端、会话、分屏及本地文件树。
- **远程模式**：登录 Lumen 账号后，发现同账号下在线的其他 Lumen 设备，并对目标设备上的整个 Lumen 编辑器进行镜像和控制。

现有远程模式要求目标设备已安装并运行 Lumen，解决的是“控制自己的另一台 Lumen 设备”。它不能替代运维、开发场景中通用的 SSH 登录。

因此新增第三种独立模式——**SSH 模式**。用户可直接连接 Linux 服务器，在 Lumen 内使用远程终端、浏览和传输文件，并查看服务器运行状态。目标服务器无需安装 Lumen，也不强制安装额外 Agent。

## 2. 产品目标

### 2.1 核心目标

1. 用户可在 Lumen 内安全地保存和管理多台 Linux 服务器。
2. 用户可通过标准 SSH 登录服务器，并获得与本地模式一致的终端、多会话和多窗格体验。
3. 用户可通过 SFTP 浏览和传输远程文件。
4. 用户可在不中断终端工作的情况下，实时查看服务器 CPU、内存、磁盘、负载、网络和运行时长等监控信息。
5. SSH 模式与现有远程模式概念清晰、数据隔离，不改变现有远程控制能力。
6. 用户登录 Lumen 账号后，SSH 服务器列表和配置自动上传到 Lumen 服务器；同账号的其他 Lumen 客户端自动同步最新配置。
7. Lumen 提供全局应用上锁能力；锁定后必须通过本机密码解锁，才能通过该设备的本地窗口查看或操作本地、远程和 SSH 工作内容；已授权控制端的既有远程控制不受影响。

### 2.2 成功标准

- 首次配置一台服务器后，用户可在 30 秒内完成连接并进入可交互 Shell。
- 已保存服务器从点击“连接”到出现 Shell 提示符，局域网/正常公网环境下 P50 小于 3 秒。
- 监控面板首屏数据在 SSH 连接成功后 5 秒内出现。
- 终端连续使用 2 小时无输入丢失、界面卡死或异常断连。
- 密码、私钥内容和私钥口令不以明文写入 Lumen 配置文件或日志。
- 两台在线客户端登录同一 Lumen 账号后，SSH 配置新增、修改和删除在目标 30 秒内完成同步。
- 私钥文件、私钥本地路径、密码和私钥口令不会上传到 Lumen 服务器。
- 用户可手动或按空闲时间自动锁定 Lumen；锁定后全部业务内容立即隐藏，正确输入本机解锁密码后恢复原工作状态。

## 3. 非目标

以下能力不进入首期 MVP：

- 替代 Prometheus、Grafana、Zabbix 等专业监控和告警系统。
- 在服务器上安装 Lumen Agent 或常驻守护进程。
- SSH 跳板机、多级 ProxyJump、SOCKS/端口转发。
- Windows Server、网络交换机等非 Linux 目标的完整适配。
- 容器、Kubernetes、数据库等应用层监控。
- 跨设备同步密码、私钥文件、私钥内容、私钥本地路径或私钥口令。
- SSH 会话断线后的进程级无感续接。未使用 tmux/screen 时，断线后只能新建 Shell。
- 多人共享服务器凭据、企业权限审批和堡垒机审计。
- 把应用上锁等同于磁盘加密、操作系统账号隔离或抵御拥有本机管理员权限的攻击者；它主要防止离席期间他人直接查看和操作 Lumen。

## 4. 三种模式的边界

| 维度 | 本地模式 | 远程模式 | SSH 模式 |
|---|---|---|---|
| 操作对象 | 当前电脑 | 另一台运行 Lumen 的设备 | 任意可访问的 Linux 服务器 |
| 连接协议 | 本地 PTY | Lumen 协议，WebSocket/P2P | 标准 SSH 2 + SFTP |
| 是否要求目标机安装 Lumen | 当前机已安装 | 是 | 否 |
| 是否要求登录 Lumen 账号 | 否 | 是 | 使用 SSH 不要求；跨设备配置同步要求登录 |
| 会话/分屏 | 本机 Shell | 镜像并控制目标 Lumen 会话 | 每个窗格对应远程 SSH Shell |
| 文件树 | 本地文件 | 目标 Lumen 设备文件 | SFTP 远程文件 |
| 监控 | 不提供 | 不在本需求内 | Linux 服务器监控 |
| 典型用途 | 本机开发 | 跨设备继续工作、远程接管 | Linux 开发、部署、运维 |

产品文案中必须始终使用“远程模式”和“SSH 模式”两个独立名称，不把 SSH 归入现有远程模式。

## 5. 目标用户与使用场景

### 5.1 目标用户

- 通过 Windows 电脑连接 Linux 开发机的开发者。
- 管理 VPS、云服务器、NAS 或家庭服务器的个人用户。
- 需要同时观察服务器状态并执行部署、排障命令的运维人员。

### 5.2 核心场景

1. **日常登录**：从服务器列表选择已保存主机，一键进入 Shell。
2. **首次连接**：填写地址、端口、用户名和认证方式，核对主机指纹后保存并连接。
3. **多任务工作**：在同一服务器上新建多个会话或分屏，分别查看日志、运行命令和编辑文件。
4. **文件操作与编辑**：通过 SFTP 文件树上传、下载、新建、重命名和删除文件；远程/SSH 文本文件可在 Lumen 内直接编辑并安全写回。
5. **资源排障**：命令执行变慢时展开监控面板，查看 CPU、内存、磁盘、负载和网络变化。
6. **网络波动**：连接断开后保留已有输出，明确提示断线原因，并允许一键重连。
7. **临时离席**：用户使用快捷键立即上锁，或在一段时间没有本机人工操作后由 Lumen 自动上锁。
8. **返回工作**：锁定界面不展示任何终端、服务器或监控内容；用户输入正确密码后回到锁定前的模式、会话和布局。

## 6. 产品信息架构

### 6.1 模式入口

顶栏模式切换由当前的“本地 / 远程”扩展为：

`本地 | 远程 | SSH`

- 三种模式互斥，当前模式使用现有选中态样式。
- 默认仍进入用户上次使用的模式；旧版本升级后沿用原值，不改变用户习惯。
- 未登录 Lumen 账号也可以进入 SSH 模式，但服务器配置只保存在本机；登录后自动启用账号级云同步。
- 切换模式不主动断开已有 SSH 连接；连接可在后台保持。
- 用户主动退出应用、删除服务器或点击断开时，才关闭相应连接。

### 6.2 SSH 模式布局

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ 本地  远程  [SSH]                                      头像 / 窗口控制    │
├────────────────────────────────────────────────────────────────────────────┤
│ 工具栏：服务器栏｜会话栏｜文件树｜监控｜分屏操作                          │
├──────────────┬────────────┬─────────────────┬──────────────────────────────┤
│ 服务器列表   │ SSH 会话   │ SFTP 文件树     │ 终端工作区                   │
│ ▾ 生产环境(2)│            │                 │                              │
│   ● prod-01  │ shell-1    │ /home/user      │ $ uptime                     │
│   ● prod-02  │ logs       │ ├─ app          │ ...                          │
│ ▸ 测试环境(3)│            │ └─ logs         │                              │
│   未分组(1)  │            │                 │                              │
├──────────────┴────────────┴─────────────────┴──────────────────────────────┤
│ 可折叠监控条：CPU｜内存｜负载｜磁盘｜网络｜运行时长｜[查看详情]           │
└────────────────────────────────────────────────────────────────────────────┘
```

布局原则：

- 左侧第一列为 SSH 服务器列表，对应远程模式中的设备列表位置。
- 顶部工具栏提供“显示/隐藏 SSH 服务器列表”按钮，图标、热区、提示、状态反馈和布局行为与远程模式的设备列表按钮一致；隐藏后服务器栏不占用宽度，再次点击恢复用户上次使用的栏宽。
- 第二列复用现有会话列表；会话归属于当前服务器。
- 第三列为当前服务器的 SFTP 文件树。
- 中央工作区复用现有终端渲染、分屏、复制粘贴、链接和快捷键能力。
- 服务器监控默认显示为工作区底部的可折叠摘要条；点击“查看详情”后，在工作区内打开详情抽屉，不新开系统窗口。
- 服务器栏、会话栏、文件树和监控条均可独立显示或隐藏，并记住用户选择。

### 6.3 全局锁定层

- 应用锁是位于整个 Lumen 外壳之上的最高层状态，不属于本地、远程或 SSH 任一模式。
- 一旦锁定，本机窗口停止渲染顶栏模式切换、服务器列表、会话、文件树、终端、监控、设置页、登录页、弹窗和通知等业务内容；后台业务处理与已授权远程镜像管线继续运行。
- 窗口内容区只显示独立解锁界面；可保留最小化、关闭等必要窗口控制，但不得通过任何菜单绕过解锁进入业务界面。
- 解锁成功后恢复锁定前的模式、激活会话、窗格布局、滚动位置和面板状态。

### 7.1 开发分支约束

- 与 SSH 无关的 P0 功能只在当前 `main` 分支开发：应用锁、远程配对码复制、备用屏 TUI 回到底部兼容。
- 所有 SSH 相关功能从 P1 开始排期，只在独立分支 `feature/ssh-mode` 开发。
- `main` 不直接接收 SSH 模式、SSH 数据模型、SSH 协议、SFTP、服务器监控或 SSH 配置同步的实现提交。
- P0 在 `main` 验证稳定后，`feature/ssh-mode` 再合入最新 `main`，复用应用锁和配对体验能力。
- SSH 分支按 P1 → P2 → P3 顺序形成可独立验收的提交，不把后续能力提前混入 P1。

## 8. 详细需求

### 8.1 服务器列表

服务器列表每项显示：

- 服务器名称。
- 主机地址或别名。
- 状态圆点：连接中、正常、告警、断开。
- 已连接时显示延迟；未连接时不显示伪造的在线状态。
- 存在资源告警时显示橙色或红色角标。

列表行为：

- 单击：选中服务器，展示其会话、文件树和最后一次监控状态。
- 双击：连接；已连接时切换到最近使用的会话。
- 右键：连接/断开、编辑、复制配置、删除。
- 顶部提供“新增服务器”“新建分组”和搜索入口。
- 服务器按用户自定义分组展示；没有所属组的服务器进入系统内置的“未分组”区域。
- 删除服务器前二次确认；若正在连接，明确提示将同时关闭该服务器的全部 SSH 会话。

空状态应给出：

- 主按钮“新增服务器”。
- 次按钮“导入 SSH 配置”（P2 未实现时不显示）。
- 一句话解释 SSH 模式不要求服务器安装 Lumen。

#### 8.1.1 服务器分组

分组模型：

- “未分组”是系统内置的虚拟区域，始终位于服务器列表底部，不能重命名或删除。
- 用户分组拥有稳定 ID、名称、排序值、折叠状态和创建/更新时间。
- 分组名称去除首尾空格后必填，长度为 1–50 个字符；同一账号内不允许重名，比较时不区分大小写。
- 分组允许为空；空分组显示“将服务器拖到这里”占位。
- 分组标题显示名称和服务器数量；组内存在已连接、告警或同步失败服务器时，可显示对应汇总角标。

分组操作：

- 点击“新建分组”输入名称并创建；创建成功后新分组进入编辑态，便于继续重命名。
- 分组右键菜单提供“重命名”“新建服务器到此组”和“删除分组”。
- 分组可折叠/展开，折叠状态按当前设备持久化，不要求跨设备同步。
- 拖动分组标题可调整分组顺序。
- 删除分组必须二次确认，并显示组内服务器数量。
- **删除分组只删除组，不删除服务器**；组内服务器全部移动到“未分组”，现有 SSH 连接、会话、凭据和监控不受影响。

服务器拖放：

- 拖动服务器条目到分组标题或组内容区，可将服务器移入该组。
- 拖到其他分组可完成跨组移动。
- 拖到“未分组”可移出当前组。
- 在同一分组内拖动可调整服务器顺序。
- 拖动悬停在已折叠分组上 600ms 后自动展开，并显示明确的放置高亮和跟手预览。
- 放到无效区域或按 `Esc` 时取消拖动，服务器保持原位置。
- 移动分组或服务器只改变组织关系和排序，不触发连接、断开或重新认证。
- 右键菜单同时提供“移动到分组”，作为键盘操作和拖放操作的等价入口。
- 搜索筛选生效时，为避免隐藏条目导致误排序，禁用拖放排序；仍可通过“移动到分组”完成归组。

### 8.2 新增/编辑服务器

P1 表单字段：

| 字段 | 规则 |
|---|---|
| 名称 | 必填，默认取主机地址，可重复但应提示 |
| 主机 | 必填，支持域名、IPv4、IPv6 |
| 端口 | 默认 22，范围 1–65535 |
| 用户名 | 必填 |
| 认证方式 | 密码 / 私钥 |
| 密码 | 密码认证时显示；默认不明文展示 |
| 私钥 | 选择私钥认证后立即显示本机文件选择按钮；新建配置必须选择存在的文件 |
| 私钥口令 | 选择私钥文件后显示；私钥加密时使用，默认不明文展示 |
| 初始目录 | 可选；连接后尝试进入，失败则停留在用户家目录并提示 |
| 分组 | 可选，默认“未分组”；下拉选择已有组，并提供“新建分组”快捷入口 |
| 连接超时 | 默认 10 秒 |
| Keepalive | 默认 30 秒 |

表单操作：

- “测试连接”：验证网络、主机指纹和认证，不创建持久终端会话。
- 切换为私钥认证后必须立即在当前表单选择本机私钥，不得先保存配置、再到首次双击连接时补选；表单所选私钥可直接用于“测试连接”，保存后写入本机绑定。
- “保存”：仅保存配置。
- “保存并连接”：保存后立即进入 SSH 工作区。
- 在新建或编辑服务器时修改分组，效果与列表拖放一致，不影响服务器认证和已有连接。
- 测试连接成功后显示远端系统、主机名及认证成功信息。
- 测试失败必须区分 DNS、超时、拒绝连接、主机密钥、认证和协议不兼容。
- 私钥文件、文件内容、文件路径和私钥口令均不得进入 SSH 同步数据或上传 Lumen 服务器；仅云同步后缺少本机绑定、文件被删除/失效或认证失败时，连接阶段才允许重新绑定本机私钥。

### 8.3 凭据与主机身份安全

1. 密码和私钥口令存入操作系统安全凭据存储；配置文件只保存凭据引用，云端同步记录不包含凭据引用。
2. 私钥内容不复制进 Lumen 数据目录；私钥文件及其本地路径只保存在当前设备，绝不上传到 Lumen 服务器。
3. 日志不得记录密码、私钥内容、私钥口令或完整认证报文。
4. 首次连接未知主机时弹出确认框，显示：
   - 主机和端口。
   - 密钥类型。
   - SHA-256 指纹。
   - “信任并继续”与“取消”。
5. 已保存主机指纹发生变化时必须阻断连接，不允许静默继续；提示可能是服务器重装，也可能存在中间人攻击。
6. 用户只能在服务器编辑页通过明确操作删除旧指纹并重新验证。
7. SSH 模式不依赖 Lumen 登录状态；登录账号只用于启用服务器配置云同步，不参与 SSH 协议认证。
8. 退出 Lumen 账号会停止云同步，但不得删除已经保存在当前设备的 SSH 配置、凭据和私钥绑定。
9. 密码、私钥文件、私钥内容、私钥本地路径和私钥口令均不得进入云同步数据。

### 8.4 连接生命周期

连接状态定义：

`未连接 → 连接中 → 验证主机 → 认证中 → 已连接 → 重连中/已断开/连接失败`

要求：

- 任何连接阶段超过设定超时时间，应终止并给出阶段化原因。
- 同一服务器的多个终端窗格可共享底层 SSH 连接，但每个窗格拥有独立 PTY/Shell 通道。
- 切换到本地或远程模式后，已连接的 SSH 会话继续在后台运行。
- 用户关闭服务器最后一个会话时不自动删除服务器配置。
- 用户主动点击“断开”时，关闭该服务器全部终端和 SFTP 通道。
- 网络异常断开时：
  - 保留终端最后画面并进入只读状态。
  - 顶部和服务器行同时显示断线状态。
  - 提供“立即重连”。
  - 可按 1、2、5、10、30 秒退避自动重连，最多 5 次；用户可取消。
  - 重连成功后创建新 Shell，不承诺恢复原进程；必须在提示中说明。
- 应用退出时正常关闭连接，不在后台残留进程。

### 8.5 SSH 终端

P1 要求：

- 申请远程 PTY，并随窗格尺寸变化同步 rows、cols。
- 默认使用服务器账户的登录 Shell。
- 默认 UTF-8；无法识别的字节使用替代字符显示，不使会话崩溃。
- 支持终端颜色、光标、鼠标上报、备用屏幕、vim、top/htop、tmux 等 TUI。
- 复用现有复制、粘贴、选区、滚动回看、可点击链接、输入法和多窗格能力。
- 每个 SSH 会话的自动名称默认跟随该会话当前工作目录（cwd）的末级目录名；cwd 为 Linux 根目录时显示 `/`。
- 用户可通过会话行右键“重命名”或双击会话名称进入行内编辑，自定义名称去除首尾空格后保存。
- 一旦用户手动设置非空名称，该会话名称固定为自定义值，不再随后续 `cd` 或 cwd 更新变化；将自定义名称清空并确认后恢复自动命名，并立即按当前 cwd 重新计算名称。
- 每个 SSH 会话只归属于一台服务器，同一会话内的全部窗格使用该服务器，避免监控、文件树和凭据归属混乱。
- 新建会话时默认使用当前服务器，也可从服务器下拉菜单选择其他服务器；新建窗格始终继承当前会话的服务器。
- 文件拖入终端不自动上传，避免误操作；上传走文件树或明确的上传动作。
- 本地命令历史与远端命令历史默认分开，避免把服务器敏感命令混入本机历史。
- 首期允许经典终端输入模式作为稳定兜底；Blocks/智能输入只有在远端 Shell Integration 成功时启用，失败不得影响基本 SSH 使用。

### 8.6 SFTP 文件树

P2 支持：

- 默认打开远端用户家目录或配置的初始目录。
- 展开目录时按需加载，不递归预取整棵目录树。
- 目录级刷新和后台递归搜索；Linux 点前缀的隐藏文件与隐藏目录始终显示，SSH 文件树不提供单独的“显示隐藏文件”按钮。
- 上传本地文件/文件夹。
- 下载远程文件/文件夹。
- SSH 文件树选中项后，`Ctrl+C` 与右键“复制”必须写入同一份文件剪贴板状态；在可粘贴目录按 `Ctrl+V` 与右键“粘贴到此目录”必须进入同一条传输、冲突处理和刷新链路。
- 从 SSH 文件树复制的远端文件或目录可在切换到 Lumen 本地模式后，粘贴到本地文件树的目标目录；切换模式不得清空待粘贴的 SSH 项或中断其来源 SSH 会话。
- SSH 远端项粘贴到本地时若目标目录已有同名文件或目录，必须在写入前显示“覆盖、跳过、取消”选择；覆盖不得因传输或最终替换失败而破坏原有本地项，跳过和取消不得改动目标。
- SSH 到本地的文件与目录传输开始时立即给出可见反馈，结束时明确显示成功或失败；成功后刷新准确的本地目标目录，失败时保留可重试信息且不得遗留可见的半成品。
- 新建文件、新建文件夹、重命名、删除。
- 双击目录进入；双击文件下载到临时目录后调用本地默认程序打开。
- 右键文件选择“编辑”时，在 Lumen 工作区打开内置文本编辑器；双击文件不得触发内置编辑或自动回传。
- 大文件传输显示方向、文件名、已传大小、总大小、速度和取消按钮。
- 删除操作必须二次确认，并明确是服务器端删除；首期不承诺远端回收站。
- SFTP 无权限时，终端仍可正常使用，文件树显示权限错误而不是断开整条 SSH 连接。
- 当前 SSH 会话成功执行 `cd` 后，文件树根目录自动跟随该会话上报的当前路径；每个会话独立保存文件树根、展开、选择和搜索状态。
- 目录双击和“进入文件夹”仅在对应 Shell 可安全接收命令时注入 `cd`；前台程序或 TUI 运行期间必须阻止注入并给出提示。
- SSH 文件树的行样式、展开、选择、搜索、右键菜单、复制粘贴、新建和删除确认等可见行为应与本地、远程文件树保持一致；Linux 路径和文件名始终使用 Linux 语义校验与转义。

#### 8.6.1 远程与 SSH 内置文本编辑器

远程模式和 SSH 模式共用同一套 Lumen 内置文本编辑器：

- 入口固定为文件右键菜单“编辑”，不是双击。
- 双击文本文件仍下载到控制端临时目录并交给系统默认本地编辑器；之后在本地编辑器保存只修改该本地副本，不自动上传或覆盖远端文件。
- 内置编辑器保存时直接写回原远程文件，并显示加载中、未保存、保存中、已保存和错误状态。
- 顶部使用与 VS Code 一致心智模型的文件 Tab 栏；右键编辑新的远程文件时新增 Tab，已打开文件只切换到原 Tab，不重复创建；各 Tab 独立保存正文、光标、滚动位置、撤销历史、加载/错误状态和未保存状态。
- 支持同时打开和编辑多个远程/SSH 文件，可在不同设备或 SSH 会话的文件之间切换；后台 Tab 的异步读取和保存结果必须按稳定文档标识正确回到对应 Tab，不得串写到当前 Tab。
- 支持 `Ctrl+S` 保存当前 Tab、`Ctrl+F` 查找、`Ctrl+W` 关闭当前 Tab、读取失败重试，以及保存期间继续输入。
- 点击 Tab 关闭按钮、按 `Ctrl+W` 或关闭整个编辑器时，若目标文件存在未保存修改，必须显示“保存、不要保存、取消”确认；选择保存后仅在远端保存成功后关闭，保存失败时保留 Tab 和正文。
- 根据文件扩展名自动识别常用语言，并提供接近 VS Code 默认主题的关键字、字符串、注释、数字、函数、类型和属性颜色；深色与浅色主题均需保持可读对比度，未知类型回退为纯文本。
- 编辑时自动提供基于当前语言关键字、常用内建符号、代码片段和当前文档标识符的智能提示；输入首字符即可出现高价值语言候选，支持 `Ctrl+Space` 主动唤起、方向键选择、`Enter`/`Tab` 接受、`Esc` 关闭，建议弹层尽量靠近光标且不能遮挡当前输入行。
- 正文编辑视口的宽高始终铺满中央可用内容区，不能随文本长短收缩或增长；长文件和超长行只在编辑器内部滚动。按 `Enter` 时继承当前行 Tab/空格缩进，位于匹配括号中间时自动展开内层空行，闭合符行自动回退一级；自动缩进和代码片段均必须可一次 `Ctrl+Z` 撤销。
- 编辑器整体采用 VS Code 式信息层级：顶部文件 Tab、路径提示、单一主编辑区、查找条和底部状态栏；状态栏显示行列、编码、换行符和语言，选中/悬停/焦点与 Lumen 主题保持一致。
- 首期只编辑不超过 1 MiB 的 UTF-8 文本；UTF-8 BOM 与统一的 LF/CRLF 换行需要往返保真。二进制、非法 UTF-8、混合换行及超限文件给出明确错误，不得静默改码。
- 普通保存必须携带打开或上次保存时的文件版本，提交前发现服务器文件已变化时进入冲突界面，由用户选择重新加载、保留当前编辑或明确强制覆盖。
- 写回使用同目录临时文件、落盘同步和原子替换；保存失败不得破坏原文件，临时文件必须清理。
- SSH 写回优先使用 OpenSSH `posix-rename@openssh.com` 扩展完成原子覆盖；服务器不支持原子覆盖时必须明确报错并保留原文件，禁止用“先删除目标再重命名”模拟覆盖。
- 文档身份必须绑定远程控制会话代次或 SSH 运行实例与会话 ID；切换账号、服务器、被控设备或会话后，相同路径不得复用旧设备内容或写入新设备。
- 网络断开、会话关闭、账号切换或请求通道拥塞时，编辑器必须退出永久“加载中/保存中”状态，保留用户尚未保存的缓冲并显示可恢复错误。
- 远端路径、文件正文和内容摘要不得进入普通日志、遥测、云同步或通知正文。

### 8.7 服务器监控

#### 8.7.1 采集原则

- 首期为 **Agentless**：通过已建立的 SSH 连接执行只读采集命令，或读取 `/proc` 等标准系统信息。
- 不要求 root/sudo 权限。
- 监控使用独立、低优先级的 SSH 通道，不向用户当前终端写入命令或输出。
- 监控失败不得影响终端和文件传输。
- 监控采集命令、标准错误和返回数据均设置大小与执行时间上限，防止异常服务器拖垮客户端。
- 用户可在服务器配置中关闭监控。

#### 8.7.2 摘要监控条

连接成功后默认显示以下指标：

| 指标 | 展示内容 | 默认告警 |
|---|---|---|
| CPU | 总使用率、最近 60 点迷你趋势 | 持续 3 个采样点 ≥ 90% 为红色 |
| 内存 | 已用/总量、使用率 | ≥ 85% 橙色，≥ 95% 红色 |
| 系统负载 | 1/5/15 分钟 Load Average | 1 分钟负载高于 CPU 核数为橙色 |
| 磁盘 | 根分区已用/总量、使用率 | ≥ 85% 橙色，≥ 95% 红色 |
| 网络 | 当前接收/发送速率 | 默认不告警 |
| 运行时长 | uptime | 默认不告警 |
| 延迟 | SSH 往返耗时 | ≥ 300ms 橙色，≥ 1000ms 红色 |

状态颜色只用于快速识别，必须同时显示数值，不能只依赖颜色表达。

#### 8.7.3 监控详情

点击“查看详情”打开详情抽屉，展示：

- 主机名。
- Linux 发行版和版本。
- 内核版本、架构。
- CPU 型号、逻辑核心数、总使用率趋势。
- 内存总量、已用、可用、Swap。
- 1/5/15 分钟系统负载。
- 各挂载点的文件系统、总量、已用、可用和使用率。
- 汇总网络接收/发送速率及累计流量。
- 系统启动时间和运行时长。
- 最近一次成功采样时间。

首期趋势仅保留当前应用运行期间最近 60 个采样点，不落盘、不上传云端。

#### 8.7.4 采样频率

- 当前选中且监控面板可见：每 3 秒采样。
- 当前选中但监控面板收起：每 10 秒采样。
- SSH 模式在后台：每 30 秒采样。
- 应用最小化超过 5 分钟：暂停趋势采样，仅保留 keepalive；恢复后立即采样一次。
- 单次采集超时 2 秒；连续 3 次失败后显示“监控不可用”，终端连接保持。

#### 8.7.5 数据缺失

- 某项无权限或系统不支持时显示 `--`，悬停说明原因。
- 不因单个分区、网卡或命令解析失败清空其他已成功指标。
- 非 Linux 主机若能够完成 SSH 登录，可使用终端，但监控和兼容性不作首期承诺，并显示提示。

### 8.8 快捷键

建议首期快捷键：

| 操作 | 快捷键 |
|---|---|
| 切换到 SSH 模式 | `Ctrl+Shift+3` |
| 新建 SSH 会话 | 沿用 `Ctrl+T` |
| 新建窗格 | 沿用 `Ctrl+Shift+D` |
| 关闭窗格 | 沿用 `Ctrl+Shift+W` |
| 显示/隐藏文件树 | 沿用 `Ctrl+B` |
| 复制 SSH 文件树选中项 | 沿用 `Ctrl+C`，与右键“复制”等价 |
| 粘贴到 SSH/本地文件树目标目录 | 沿用 `Ctrl+V`，与右键“粘贴到此目录”等价 |
| 显示/隐藏监控 | `Ctrl+Shift+M` |
| 断线时立即重连 | `Ctrl+Shift+R`，仅在 SSH 断线提示聚焦时生效 |

所有快捷键需要进入现有快捷键设置页，并支持三语文案。

### 8.9 设置与持久化

需要在本机持久化：

- 上次使用的模式。
- 服务器非敏感配置、排序、分组和主机指纹。
- 每台服务器的会话名称、窗格布局和初始目录关联。
- SSH 模式下各栏位的显示状态和宽度。
- 监控开关和展示状态。
- 应用锁开关、密码校验数据、锁定快捷键、自动锁定时长和当前锁定状态；全部仅保存在本机。

不持久化：

- 监控历史趋势。
- 终端内存中的完整输出。
- 明文密码、私钥内容和私钥口令。
- 当前 SSH 连接句柄或认证会话。

兼容要求：

- 现有布尔型“本地/远程”视图配置升级为三态后，旧值 `false` 映射“本地”，`true` 映射“远程”。
- 升级不得丢失当前布局、远程设备设置、主题、语言或会话数据。

### 8.10 SSH 配置云同步

#### 8.10.1 启用条件与基本行为

- 用户未登录 Lumen 账号时，SSH 配置仅保存在当前设备，SSH 连接能力正常可用。
- 用户登录 Lumen 账号后，客户端自动上传该账号下的 SSH 服务器列表和可同步配置，并自动拉取云端最新数据。
- 同一账号登录的其他 Lumen 客户端自动获得最新 SSH 服务器列表和配置，无需手动导入或导出。
- 本地新增、修改、复制、排序、归组和删除服务器，以及新建、重命名、排序或删除分组后，客户端应自动触发增量上传。
- 客户端启动、账号登录、网络恢复和进入 SSH 模式时，应主动拉取一次最新变更；在线期间周期同步。
- 离线状态下允许继续编辑，变更进入本地待同步队列；网络恢复后自动上传并合并。
- 退出账号只停止上传和拉取，不强制断开当前 SSH 会话，也不删除本机缓存。

#### 8.10.2 同步范围

| 数据 | 是否同步 | 说明 |
|---|---|---|
| 服务器配置 ID | 是 | 使用稳定 UUID，供多端识别同一条配置 |
| 名称、主机、端口、用户名 | 是 | SSH 连接基础配置 |
| 分组 ID、名称和顺序 | 是 | 分组作为独立记录同步，使用稳定 UUID |
| 服务器所属分组和组内顺序 | 是 | `group_id` 为空表示“未分组” |
| 服务器备注 | 是 | 保持多端列表一致 |
| 认证方式 | 是 | 仅同步“密码/私钥”等类型，不同步实际凭据 |
| 初始目录、超时、Keepalive | 是 | 连接行为配置 |
| 监控开关、采样偏好 | 是 | 保持服务器级偏好一致 |
| 已信任主机指纹 | 是 | 新设备用同步指纹校验目标主机；指纹变化仍必须阻断 |
| 密码 | **否** | 只存当前设备的操作系统安全凭据存储 |
| 私钥文件和私钥内容 | **否** | 绝不上传、绝不进入同步接口 |
| 私钥本地路径 | **否** | 路径只对当前设备有效，也可能暴露本机目录信息 |
| 私钥口令 | **否** | 只存当前设备的操作系统安全凭据存储 |
| 操作系统凭据引用 | **否** | 引用只对当前设备有效 |
| 应用锁密码、校验数据及锁定设置 | **否** | 属于设备本地安全设置，不随账号同步 |
| 活跃连接、终端输出、监控历史 | **否** | 属于运行态数据 |

#### 8.10.3 私钥认证的跨设备行为

- 私钥认证配置同步到新设备后，服务器仍出现在列表中，但状态显示“需要绑定本机密钥”。
- 用户首次连接前必须在新设备上重新选择本地私钥文件；完成后只在本机保存该配置 ID 与私钥路径的绑定。
- 同一条云端服务器配置允许不同设备绑定不同的本地私钥路径。
- 未绑定私钥时不得自动回退到密码认证，也不得尝试从其他设备或 Lumen 服务器下载密钥。
- 一台设备修改或删除本机私钥文件，不影响其他设备已经建立的本地密钥绑定。

#### 8.10.4 同步与冲突规则

- 每条服务器配置使用稳定 `ssh_profile_id`，服务端为变更分配单调递增版本号，客户端按同步游标拉取增量。
- 每个用户分组使用稳定 `ssh_group_id`；“未分组”是客户端虚拟区域，不在云端创建对应记录。
- 不同服务器配置的并发变更按记录独立合并。
- 同一配置发生并发修改时，以服务端最终接收的最新版本为准，并保留明确的 `updated_at` 和 `updated_by_device` 供诊断。
- 删除使用墓碑记录同步，防止已删除服务器被离线设备重新上传“复活”。
- 分组删除也使用墓碑；其他客户端收到删除后，将该组内服务器移动到“未分组”，不得连带删除服务器。
- 若离线客户端尝试把服务器移动到一个已被其他设备删除的分组，服务端保留服务器配置但将其归入“未分组”，不得恢复已删除分组。
- 分组顺序和组内服务器顺序发生并发修改时，以服务端最新版本为准；折叠状态属于设备本地 UI 偏好，不参与冲突合并。
- 本地上传成功前不得清除待同步队列；重复提交必须幂等。
- 同步失败不影响 SSH 使用，界面显示“等待同步”或“同步失败”，并自动重试。

#### 8.10.5 账号隔离与服务端安全

- Lumen 服务器必须按账号隔离 SSH 配置，任何客户端只能读写当前鉴权账号的数据。
- SSH 配置通过 TLS 上传和下载；生产环境服务端地址必须使用 `HTTPS/WSS`，明文 `HTTP/WS` 只允许本机回环开发环境或用户显式启用的不安全调试模式。
- 同步接口和服务端日志不得记录密码、私钥内容、私钥路径或私钥口令。
- 登录 token 必须绑定其实际签发的规范化 Lumen 服务端来源；启动、续期、心跳、远程控制和 SSH 同步仅可向完全相同的来源发送该 token。
- 修改 Lumen 服务端地址时，客户端必须先清除旧 token、停止旧账号网络任务并要求重新登录，不得向新地址试发旧 token 或旧账号 SSH 快照。
- 客户端本地缓存按“规范化 Lumen 服务端来源 + Lumen 账号”双重区分；即使两个自建服务端出现相同账号 ID，也不得共享库存、同步游标、待上传队列或本机凭据绑定。
- 未登录状态创建的本地配置，只能由某一“服务端来源 + 账号”首次认领并上传；已经归属于其他来源或账号的缓存不得参与合并。
- 客户端必须把未知服务端错误转换为长度受限的本地安全提示，禁止把服务端原始正文、控制字符或鉴权信息写入日志和通知。
- 服务端数据库中的主机地址、用户名等信息按敏感用户数据保护。

### 8.11 应用上锁与解锁

> 本节是 Lumen 全局能力，覆盖本地、远程和 SSH 三种模式。它被收录在本 PRD 中，是因为 SSH 服务器信息、终端输出和文件内容需要统一的离席保护。

#### 8.11.1 设置入口

设置页新增“安全 → 应用锁”区域，包含：

| 设置项 | 行为 |
|---|---|
| 启用应用锁 | 默认关闭；开启时必须先设置并确认本机解锁密码 |
| 修改密码 | 必须先验证当前密码 |
| 关闭应用锁 | 必须先验证当前密码 |
| 立即锁定 | 保存当前设置并立刻进入锁定界面 |
| 锁定快捷键 | 默认 `Ctrl+Shift+L`，支持在现有快捷键设置中修改和恢复默认 |
| 自动锁定 | 关闭 / 1 / 5 / 10 / 15 / 30 / 60 分钟；首次开启建议值为 10 分钟 |
| 启动时锁定 | 可选开关；开启后每次启动 Lumen 都先显示解锁界面 |
| 系统恢复后锁定 | 默认开启；Windows 会话锁定、系统睡眠或远程桌面断开后，再次回到桌面时保持 Lumen 锁定 |

要求：

- 全新安装和旧版本升级后的应用锁均默认关闭；旧配置缺少应用锁字段时必须补为关闭，不得在启动时显示解锁界面。
- 应用锁未开启时，锁定快捷键、空闲计时和系统恢复锁定均不生效。
- 解锁密码是当前设备的 Lumen 应用锁密码，不是 Lumen 账号密码，也不是任何 SSH 服务器密码。
- 密码长度为 8–128 个字符，支持中文、空格和符号；设置时需要二次确认。
- 新密码两次不一致、当前密码错误或快捷键冲突时，不保存设置并给出明确提示。
- 应用锁设置全部为设备本地设置，不上传到 Lumen 服务器，也不随账号同步到其他客户端。

#### 8.11.2 锁定触发

应用可通过以下方式进入锁定状态：

- 用户按下已配置的锁定快捷键。
- 用户点击设置页“立即锁定”。
- 达到配置的系统无人工操作时长。
- 开启“启动时锁定”后启动应用。
- 开启“系统恢复后锁定”后，从 Windows 锁屏、睡眠或远程桌面断开状态恢复。
- 应用在锁定状态下退出或异常终止，再次启动时必须保持锁定。

“人工操作”的判定：

- Windows 首期使用系统级最后输入时间，识别当前设备上的键盘、鼠标和触摸操作；用户正在其他应用中工作时也视为有人工操作。
- PTY/SSH 输出、监控刷新、文件传输、云同步、定时任务和动画重绘都不能重置空闲计时。
- Lumen 远程控制端发来的输入不计为被控设备的本地人工操作，也不能阻止被控设备按本地空闲规则上锁。
- 修改自动锁定时长后立即按新阈值重新计算；若当前空闲时间已经超过新阈值，则设置页关闭后立即锁定。

#### 8.11.3 锁定界面

锁定后整个窗口内容区替换为独立解锁界面，至少包含：

- Lumen 标识。
- “Lumen 已锁定”状态文字。
- 密码输入框，默认隐藏字符。
- 显示/隐藏密码按钮。
- “解锁”按钮。
- 密码错误、等待重试和 Caps Lock 提示。
- 存在远程控制会话时显示不含设备名称的提示：“已授权的远程控制仍在进行”。

交互要求：

- 锁定界面出现时焦点直接进入密码输入框，按 `Enter` 提交，按 `Esc` 清空输入。
- 不显示模糊后的终端截图、服务器名称、文件路径、账号邮箱、监控数值、通知正文或其他业务信息。
- 锁定状态下禁止打开设置、头像菜单、上下文菜单、命令面板、文件选择器和系统托盘业务菜单。
- 可保留窗口最小化和关闭按钮；关闭应用不能改变或绕过锁定状态。
- 解锁成功后在一个 UI 帧内恢复原工作界面，不闪现中间业务内容。

#### 8.11.4 锁定期间的后台运行

- 本地 PTY 进程、SSH 连接、SSH Shell、监控采集、SFTP/文件传输和配置云同步继续运行。
- 后台终端输出继续进入各自缓冲区；本地解锁后展示最新状态。
- 锁定状态下所有本机键盘、鼠标、触摸、粘贴、拖放和 IME 输入只允许作用于解锁界面，不能进入底层终端或其他业务页面。
- 锁定期间产生的 toast、系统通知和任务栏预览必须隐藏敏感正文；解锁后可展示汇总结果。
- 锁定不清空系统剪贴板，避免破坏用户在其他应用中的数据；Lumen 自有的临时敏感输入缓冲应在锁定时清理。

#### 8.11.5 与 Lumen 远程控制的关系

- **应用上锁只限制被控设备的本地界面和本地输入，不中断 Lumen 远程控制。**
- 上锁时已经建立的远程控制会话必须保持连接，控制端继续看到正常业务界面，并能继续操作会话、窗格、终端和文件。
- 远程控制画面不得切换成被控设备的本地解锁界面；应用锁层不进入远程镜像数据。
- 已配对、已授权设备可按现有规则在锁定期间重新建立远程控制；锁定状态不能被当作拒绝或断开理由。
- 需要被控设备本机首次确认、查看配对码或授予新信任关系的请求，在锁定期间不得显示任何配对信息；请求仍遵循现有有效期，解锁时若仍有效再显示处理，若已超时则按原规则失效，锁定不得延长有效期。
- 远程操作不会解锁被控设备的本地界面，也不会重置本地自动锁定计时；本地解锁后直接看到远程控制期间形成的最新状态。
- 远程控制端主动结束会话或网络断开时，被控设备仍保持锁定。

#### 8.11.6 密码与防暴力尝试

- 客户端只保存密码校验数据，不保存明文密码或可逆密文。
- 密码使用带每设备随机盐的 Argon2id 等内存困难算法生成校验值；参数应随版本可升级。
- 密码校验数据优先由操作系统安全存储保护，不进入日志、崩溃报告、遥测、剪贴板或云同步。
- 解锁、修改密码或关闭应用锁的当前密码校验共享同一失败计数；连续 5 次输入错误后等待 30 秒，之后继续失败采用递增等待，最长 15 分钟。
- 重启应用、切换系统时间或断网不得清除当前失败次数和等待截止时间。
- 等待期间仍允许关闭或最小化应用，但不能进入业务界面。
- 修改密码或关闭应用锁必须验证当前密码，成功后清除失败计数。
- 本机安全存储或应用锁配置存在但损坏时必须保持锁定并显示固定错误，不得静默回退为“未启用”。
- 应用锁定位为 Lumen 本机窗口的离席隐私保护，不替代 Windows 账号锁、BitLocker 或操作系统访问控制；P0 不承诺抵抗已经取得当前 Windows 账户文件写权限或管理员权限的攻击者篡改本地程序和数据。

#### 8.11.7 状态恢复

- 锁定前记录当前模式、激活服务器/设备、会话、焦点窗格和各面板状态。
- 解锁只恢复界面访问，不重新创建或重启仍在运行的 PTY、SSH 或远程控制会话。
- 如果锁定期间目标会话已经退出、服务器断开或远程端改变布局，解锁后展示真实最新状态，不还原过期快照。
- 多窗口能力如未来开放，每个 Lumen 窗口必须共享同一个应用锁状态；不能解锁一个窗口而让其他窗口仍泄露内容。

### 8.12 远程配对码复制

现有 Lumen 远程控制首次配对会在被控端显示 9 位数字配对码。配对码区域新增复制能力：

- 在 9 位配对码右侧显示常驻“复制”按钮，使用复制图标并提供本地化文字或悬停提示。
- 界面可继续按 `123 456 789` 分组展示，复制到系统剪贴板的内容必须是纯数字 `123456789`，不包含空格、换行、标签或说明文字。
- 点击后立即写入当前操作系统剪贴板，并显示短暂的“配对码已复制”反馈；不关闭配对界面，不改变输入焦点。
- 系统剪贴板写入失败时显示“复制失败，请手动复制”，配对流程和配对码仍保持有效。
- 配对码仍遵循原有有效期、尝试次数和一次性使用规则；复制操作不得延长有效期、增加尝试次数或生成新配对码。
- 配对成功、取消或超时后，配对码和复制按钮立即从 Lumen 界面移除。
- Lumen 不主动清空系统剪贴板，避免覆盖用户之后复制的其他内容；界面应提示配对码属于临时敏感信息。
- 配对码内容不得进入日志、遥测、崩溃报告、云同步或通知正文。
- 应用处于锁定状态时不显示配对码及复制按钮；首次配对请求按 §8.11.5 保持原有效期，解锁时仅在仍有效的情况下显示。
- 已建立或已配对的远程控制会话不受复制功能影响。

### 8.13 Codex 等备用屏 TUI 回到底部

当前 Codex CLI 的普通对话主体可使用行内视图，而 transcript、diff、全屏审批等覆盖层会使用终端备用屏，并通过 Alternate Scroll 由应用自身维护滚动位置。此时备用屏没有 Lumen 本地 scrollback，不能再只根据本地 `display_offset` 判断是否显示“回到底部”。

- 对所有启用“备用屏 + Alternate Scroll”且未接管鼠标协议的 TUI 统一生效，不按 Codex 进程名硬编码。
- 用户向上滚动超过一屏后，在当前窗格底部显示既有样式的“回到底部”浮动按钮；向下回到底部、退出备用屏或关闭 Alternate Scroll 后隐藏。
- 该滚动距离仅是 Lumen 对输入行为的本地提示；终端协议没有读取 TUI 内部真实滚动位置的通用接口，界面不得把它展示成精确行数。
- 点击按钮时向 TUI 发送一次无修饰键 `End`，由应用把自己的 viewport 跳到真实底部；普通 VT 使用标准 End 序列，DEC 9001 模式使用 Win32 `VK_END` 的按下与抬起事件。
- 不得用 `Ctrl+End`、重复 `PageDown` 或仅修改 Lumen 本地 Grid 代替；这些行为无法可靠控制 Codex 的应用内 viewport。
- 点击处理必须在执行前重新核对当前会话仍处于对应备用屏模式，防止上一帧生成的按钮在模式切换后把 `End` 注入普通 Shell。
- 原有主屏本地 scrollback 的按钮行为保持不变；两种回到底部动作共享视觉样式，但按目标滚动所有权分别执行。

## 9. 异常与提示文案

| 场景 | 用户可见反馈 | 可执行动作 |
|---|---|---|
| DNS 解析失败 | 无法解析服务器地址 | 编辑配置、重试 |
| TCP 超时 | 连接超时，显示主机和端口 | 重试、编辑配置 |
| 连接被拒绝 | 目标端口拒绝连接 | 重试、编辑端口 |
| 主机未知 | 展示指纹确认 | 信任并继续、取消 |
| 主机指纹变化 | 高风险阻断提示 | 取消、进入编辑页重新验证 |
| 密码错误 | 认证失败，不暴露服务端敏感细节 | 重新输入、编辑配置 |
| 私钥文件不存在 | 显示本地路径已失效 | 重新选择私钥 |
| 私钥口令错误 | 无法解锁私钥 | 重新输入 |
| SFTP 不可用 | 文件树不可用，终端仍可用 | 重试文件树 |
| 内置编辑文件已被外部修改 | 阻止普通保存并保留当前编辑缓冲 | 重新加载、保留编辑、明确覆盖 |
| 编辑期间会话断开或切换 | 结束加载/保存等待并保留未保存缓冲 | 重连后重新打开，或复制当前内容 |
| 文件不是受支持的 UTF-8 文本 | 不读取、不改写原文件 | 使用双击下载并交给本地程序处理 |
| 监控不可用 | 指标显示 `--` 和原因 | 重试监控 |
| 网络断开 | 终端只读、显示重连进度 | 立即重连、取消 |
| 服务器主动关闭 | 显示服务器已关闭连接 | 重连 |
| 解锁密码错误 | 密码错误，显示剩余免等待尝试次数 | 清空后重试 |
| 解锁失败次数过多 | 显示下一次可尝试的倒计时 | 等待、最小化或关闭 |
| 应用锁安全存储不可用 | 不允许静默关闭锁；显示本机安全存储异常 | 重试、退出应用 |
| 锁定时收到首次配对请求 | 不显示配对码和设备信息 | 解锁后若请求仍有效则处理 |

所有错误需提供可复制的简短技术详情，但默认不展示堆栈、原始凭据或大段协议日志。

## 10. 非功能要求

### 10.1 性能

- SSH 终端输入到本地回显处理不额外引入可感知卡顿。
- 监控开启后，空闲状态客户端 CPU 增量目标小于 2%，单台服务器内存增量目标小于 20 MiB。
- 服务器列表支持至少 200 条配置；同时维持 20 台服务器连接时界面仍可正常操作。
- 文件树单目录 10,000 项时采用渐进加载或虚拟化，不能阻塞 UI 主线程。

### 10.2 稳定性

- SSH、SFTP、监控均不得在 UI 主线程执行阻塞网络操作。
- 单台服务器异常不得影响其他服务器连接。
- 监控解析失败、非法 UTF-8 或超大返回不得导致应用崩溃。
- 系统休眠/唤醒、网络切换后应正确进入断线或重连状态。
- 锁定判定和密码校验不得阻塞 UI 主线程；锁定状态切换必须是原子的，不能出现一帧业务内容泄露。
- 应用锁输入门控必须位于键盘、鼠标、IME、剪贴板、拖放、快捷键和命令分发的最外层，禁止依赖各业务页面自行判断。
- 本地锁定状态与远程镜像状态必须分离；锁定不能中断已授权远程控制，远程控制也不能改变本地锁定状态。

### 10.3 可访问性与国际化

- 新增文案全部进入现有简体中文、繁体中文、英文资源表。
- 状态不能只靠红/绿颜色区分，应配合图标、文字或数值。
- 服务器指纹、错误详情和监控数值支持键盘选择与复制。
- 常用操作可通过键盘完成，弹窗焦点顺序明确。
- 解锁界面支持完整键盘操作、屏幕阅读器标签、Caps Lock 提示和清晰的错误焦点反馈。

### 10.4 日志与隐私

- 默认日志记录连接阶段、服务器配置 ID、错误类别和耗时。
- 主机地址在普通诊断日志中可以记录；导出诊断包时提供脱敏选项。
- 用户名、远端路径和命令内容按敏感数据处理，非必要不进入 INFO 日志。
- 任何凭据不得进入日志、崩溃报告、云同步或监控数据。
- SSH 配置同步接口必须有账号鉴权、访问隔离、请求大小限制和服务端审计；审计只记录配置 ID、操作类型、设备 ID 和结果，不记录配置正文。
- 应用锁日志只允许记录锁定原因、锁定/解锁结果和失败计数，不得记录密码长度、字符信息或输入内容。

## 11. 数据指标

首期仅统计本地匿名产品事件；如果当前产品没有遥测能力，则先保留事件定义，不为本功能单独引入遥测。

建议事件：

- 进入 SSH 模式。
- 新增服务器成功/失败。
- 测试连接成功/失败类别。
- SSH 连接成功、耗时和失败类别。
- 主机指纹确认/取消/变化阻断。
- 新建 SSH 会话和窗格。
- 展开监控详情、监控采集失败。
- SFTP 上传/下载成功和失败。
- 主动断开、异常断开、重连成功/失败。
- SSH 配置上传、拉取、冲突合并和同步失败类别。
- 应用锁启用/关闭、手动/自动锁定、解锁成功和失败类别；不采集密码、空闲时长原始事件或锁定期间的业务内容。

严禁上报主机地址、用户名、指纹、路径、命令内容和凭据。

## 12. 验收标准

### 12.1 主流程

1. 顶栏可在本地、远程、SSH 三种模式间切换，重启后恢复上次模式。
2. 新用户可新增一台 SSH 服务器，完成首次指纹确认并用密码连接。
3. 用户可用带口令私钥连接同一服务器，凭据不出现在配置文件和日志中。
4. 连接后能运行 `ls`、`top`、`vim`、`sudo` 等交互命令，中文输入和 UTF-8 输出正常。
5. 同一服务器可创建至少 6 个窗格，各窗格有独立 Shell，resize 正常。
6. SFTP 文件树可完成上传、下载、新建、重命名和删除。
7. 监控条在 5 秒内显示 CPU、内存、负载、根磁盘、网络和 uptime。
8. 展开详情后能查看各挂载点和最近 60 点趋势。
9. 关闭监控后终端和 SFTP 不受影响。
10. 切换到本地或远程模式再切回，SSH 会话仍在运行。
11. 客户端 A 新增或修改 SSH 服务器后，登录同一账号的客户端 B 可在目标 30 秒内自动获得最新配置。
12. 客户端 A 删除服务器后，客户端 B 自动删除对应列表项，离线设备恢复联网后不会把该配置重新上传复活。
13. 私钥认证配置同步到客户端 B 后显示“需要绑定本机密钥”，选择本机私钥后才允许连接。
14. 用户可新建两个分组，并在新建服务器时直接选择所属分组。
15. 用户可将服务器拖入分组、跨组移动、拖回“未分组”，重启后分组与顺序保持不变。
16. 删除包含服务器的分组后，组内服务器全部进入“未分组”，已有连接和会话不中断。
17. 客户端 A 新建、重命名、排序或删除分组后，客户端 B 自动同步同样的分组结构和服务器归属。
18. SSH 会话执行 `cd` 后，仅该会话的文件树自动切换到新目录；其他会话的路径、展开、选择和搜索状态不变。
19. SSH 文件树可搜索当前目录子树，`.git`、`.ssh`、`.env` 等隐藏项默认可见，且工具栏不显示独立的“显示隐藏文件”按钮。
20. 远程和 SSH 文件右键“编辑”进入同一套 Lumen 内置编辑器，保存后服务器文件内容立即更新。
21. 远程和 SSH 文件双击只打开控制端本地副本；在系统默认编辑器中保存不会自动修改服务器文件。
22. 内置编辑器在外部并发修改时阻止普通保存并展示冲突选择；断线或关闭会话后不会永久停留在“加载中”或“保存中”。
23. 切换远程设备、SSH 会话或 Lumen 账号后，即使路径文字相同，也不会展示旧设备正文或把旧缓冲保存到新设备。
24. SSH 工具栏按钮可隐藏服务器列表，隐藏后不占用布局宽度；再次点击恢复，行为与远程模式按钮一致。
25. 同时打开至少 10 个远程/SSH 文本文件时，每个文件均有独立 Tab、正文、未保存状态和异步保存结果，切换 Tab 不丢失编辑内容。
26. 关闭未保存 Tab 或关闭包含未保存 Tab 的编辑器时出现保存确认；选择取消保持原状，选择保存仅在保存成功后关闭。
27. Rust、Python、JavaScript/TypeScript、JSON、YAML、Shell、PowerShell 等常用文件可自动显示语法颜色，未知扩展名以纯文本安全打开。
28. 输入首个标识符字符或按 `Ctrl+Space` 后出现智能提示，方向键可移动选择，`Enter`/`Tab` 接受，`Esc` 关闭；单字符阶段不混入低价值的当前文档噪音候选。
29. 空文件、单行文件、数千行文件和超长单行文件使用相同编辑器视口宽高；按 `Enter` 继承缩进，匹配括号可智能展开，输入首字符出现语言候选和代码片段，且结构化编辑可一次撤销。
30. 新建 SSH 服务器切换为私钥认证后立即显示文件选择按钮和可选口令；未选择有效本机文件时不可保存或测试，选择后测试可直接认证，保存后首次双击不再重复弹出私钥选择框。
31. SSH 文件树选中同一文件或目录后，`Ctrl+C` 与右键“复制”的结果一致；在同一目标目录按 `Ctrl+V` 与右键“粘贴到此目录”的传输结果、冲突处理和目录刷新一致。
32. 从 SSH 文件树复制远端文件或包含子目录的目录，切换到 Lumen 本地模式后可粘贴到本地文件树；遇到同名目标时显示“覆盖、跳过、取消”，传输开始及完成或失败均有明确反馈，成功后目标目录立即显示新内容。
33. 新建 SSH 会话时名称自动显示当前 cwd 的末级目录，cwd 为根目录时显示 `/`；执行 `cd` 后自动名称同步变化。用户可右键或双击会话行内修改名称，手动修改后不再跟随 cwd；清空自定义名称后立即恢复自动跟随。

### 12.2 安全与异常

1. 未知主机必须确认指纹；已知主机指纹变化必须阻断。
2. 密码错误、私钥错误、超时、拒绝连接均有不同提示。
3. 网络断开后保留最后画面并进入只读状态，可一键重连。
4. SFTP 或监控单独失败时，SSH 终端保持可用。
5. 删除正在连接的服务器时有二次确认，并关闭其全部通道。
6. 旧版本配置升级后仍保持原来的本地/远程模式选择和布局数据。
7. 检查客户端上传请求、服务端数据库、服务端日志和另一台客户端，均不存在私钥文件、私钥内容、私钥本地路径、密码或私钥口令。
8. 切换 Lumen 账号时，前一个账号的 SSH 配置不会显示或上传到新账号。
9. 云同步暂时失败或 Lumen 服务器不可用时，已有 SSH 配置和连接仍能在本机正常使用。
10. 内置编辑器写入失败、冲突、取消或客户端异常时，原远程文件保持完整且同目录临时文件被清理。
11. UTF-8 BOM、LF/CRLF 文本经内置编辑器读取并保存后字节约定保持不变；二进制、非法 UTF-8、混合换行和超过 1 MiB 的文件不会被改写。

### 12.3 应用锁与远程配对

1. 全新安装及旧版本升级后应用锁默认关闭，不出现解锁界面，也不因空闲或快捷键进入锁定。
2. 用户可在设置页主动启用应用锁、设置密码、修改锁定快捷键，并通过快捷键立即锁定。
3. 配置自动锁定时间后，达到系统无人工操作阈值会自动锁定；终端输出、监控刷新和远程输入不会延长计时。
4. 锁定后本地、远程、SSH、设置、通知和弹窗内容均不可见，只显示解锁界面。
5. 输入错误密码不能进入业务界面；输入正确密码后恢复锁定前的模式和最新运行状态。
6. 锁定期间本地 PTY、SSH、监控、文件传输和云同步继续运行，解锁后能看到期间产生的最新结果。
7. 被控端上锁前已经建立的 Lumen 远程控制不会断开；控制端可继续正常查看和操作，而被控端本地界面始终保持锁定。
8. 远程控制端结束会话后，被控端仍保持锁定；远程操作不能触发本地解锁。
9. 锁定期间收到需要首次本机确认的远程配对请求时，不显示配对信息；解锁时请求若仍在原有效期内才进入配对流程，锁定不会延长配对有效期。
10. 点击配对码旁的“复制”按钮后，系统剪贴板内容严格等于 9 位纯数字，不含显示时的分组空格。
11. 配对成功、取消或超时后复制按钮消失；复制行为不改变配对码有效期和尝试次数。
12. 应用在锁定状态退出或异常终止后重新启动，仍先显示解锁界面。
13. 检查本地配置明文、日志、遥测和云同步数据，均不存在应用锁明文密码或可逆密码。
14. 在解锁界面、修改密码和关闭应用锁入口累计输错当前密码，均使用同一失败计数；进入退避期后所有密码校验入口同时显示倒计时并禁止继续提交。
15. 在 Codex transcript 等备用屏 Alternate Scroll 界面向上滚动超过一屏后出现“回到底部”按钮，点击后 Codex 应用内 viewport 立即回到底部。
16. 同一按钮在普通主屏 scrollback 中仍执行本地 Grid 回到底部；备用屏点击不会把 `End` 错投到已经退出的普通 Shell。

## 14. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| SSH 实现的算法兼容性不足 | 某些旧服务器无法连接 | 首期明确支持范围；错误中显示协商失败类别；不静默降级到弱算法 |
| 监控命令在发行版间差异大 | 指标缺失或解析错误 | 优先使用 `/proc` 和标准 POSIX 输出；指标独立降级 |
| 监控轮询影响服务器或客户端 | 高连接数时资源上升 | 可见性分级采样、超时、低优先级通道、用户可关闭 |
| 凭据存储不安全 | 严重安全风险 | 使用操作系统凭据存储；配置和日志只保留引用 |
| 私钥或密码误入同步载荷 | 严重凭据泄漏 | 云端 DTO 使用允许列表；客户端上传前二次过滤；端到端测试扫描请求、数据库和日志 |
| 多端并发修改导致配置覆盖或删除复活 | 用户配置不一致 | 稳定配置 ID、服务端版本号、同步游标、删除墓碑和幂等上传 |
| 删除分组时误删服务器 | 连接配置和工作状态丢失 | 分组删除与服务器删除使用独立动作；删除组只移动服务器到“未分组” |
| 拖放目标不清导致服务器误归组 | 列表组织混乱 | 跟手预览、目标高亮、悬停展开、无效区域取消及右键“移动到分组”兜底 |
| 切换账号造成配置串号 | 泄露另一账号的服务器信息 | 本地缓存按账号隔离，上传前校验配置归属账号 |
| 锁定只覆盖 UI、输入仍穿透到底层 | 未授权人员可操作终端 | 在事件分发最外层建立统一锁门控，并对键盘、鼠标、IME、剪贴板、拖放和快捷键做专项测试 |
| 用户误以为上锁会停止远程控制 | 已授权控制端仍能查看和操作内容 | 设置页和锁定界面明确提示“远程控制仍在进行”，并仅允许已配对、已授权会话继续 |
| 自动锁定误判用户仍在操作 | 工作被意外打断 | Windows 使用系统级最后输入时间；阈值可关闭或调整；后台输出不计人工操作 |
| 忘记应用锁密码 | 用户无法进入 Lumen | 提供经过身份验证的恢复方案；恢复边界见待评审决策 |
| 配对码复制后留在系统剪贴板 | 临时配对信息可能被其他应用读取 | 明确敏感提示、维持短有效期和一次性规则；不擅自清空用户剪贴板 |
| 断线重连被误解为会话续接 | 用户丢失远端进程 | 明确提示新建 Shell；后续用 tmux 提供可续接方案 |
| SFTP 与 Shell 权限/路径不一致 | 文件树操作失败 | 权限错误局部展示，不影响终端；初始目录失败时回家目录 |
| 同路径跨设备误复用编辑缓冲 | 旧设备内容被写入新设备 | 文档身份绑定账号、远程会话代次、SSH 运行实例与会话 ID；保存前再次校验 |
| 编辑期间外部程序修改远端文件 | 用户修改被静默覆盖 | 条件保存、提交前版本复核和明确的冲突处理；强制覆盖只能由用户主动选择 |
| 断线或终态事件拥塞 | 编辑器永久卡在加载/保存中 | 终态可靠投递；会话失效主动结束等待并保留未保存缓冲 |
| 三种模式状态相互串扰 | 操作发往错误目标 | 模式、服务器、会话三层明确归属；切换时清理悬空输入和选区状态 |

## 15. 待评审决策

以下内容本稿给出推荐默认值，评审时可调整：

1. **SFTP 是否进入 SSH P2**：建议保留在 P2。SSH P1 先完成安全连接与终端闭环，P2 再发挥 Lumen 现有文件树和文件传输优势。
2. **监控放置位置**：建议采用“底部摘要条 + 工作区详情抽屉”，不新增常驻右侧栏，避免压缩终端宽度。
3. **断线自动重连**：建议默认开启、最多 5 次，并明确重连后是新 Shell。
4. **服务器列表是否显示离线概念**：建议只区分“已连接/未连接”，不对未连接服务器做周期探活，避免无意扫描和额外流量。
5. **SSH P1 支持的认证方式**：建议 P1 为密码和本地私钥，ssh-agent/Pageant 放 P2。
6. **非 Linux 主机行为**：建议允许尝试终端连接，但明确标注监控仅支持 Linux。
7. **忘记应用锁密码的恢复方式**：建议登录用户通过 Lumen 账号重新认证并结合当前操作系统用户验证后重设；未登录用户只能执行明确告知后果的本地安全重置，清除本机保存的凭据和私钥绑定，但不删除云端 SSH 配置。

## 16. 一句话版本定义

**Lumen 新增可分组、可跨端同步的 SSH 模式，并提供 SFTP、免 Agent 监控和全局应用锁；锁定时本地内容完全隐藏，但已授权远程控制及后台任务继续运行，私钥文件和各类密码始终不上传。**
